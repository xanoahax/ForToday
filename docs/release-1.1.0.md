ForToday ist eine schmale Windows-App für Tageslisten und eigene Listen, mit lokaler JSON-Speicherung.

Neu in 1.1.0:

- Windows-Installer mit wählbarem Installationsordner, Verknüpfungen und Deinstallation.
- Optionaler Autostart unter Menü → Einstellungen.
- Optionales Minimieren ins Tray beim Schließen. Tray-Klick öffnet das Fenster wieder; „Beenden“ schließt die App vollständig.
- Sind beide Optionen aktiv, startet ForToday mit Windows im Hintergrund.

**Download:** `ForToday-1.1.0-Setup.exe` zur Installation oder `ForToday-1.1.0-Portable.exe` ohne Installation. Windows x64. Beide Varianten verwenden denselben lokalen Datenordner. Bisherige Listen bleiben erhalten.

Die Dateien sind nicht mit einem Code-Signing-Zertifikat signiert. Prüfsummen stehen in `SHA256SUMS.txt`.
